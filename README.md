# Printy Landing Page

Dark, blue-themed landing page for showcasing 3D printing projects with interactive buttons and motion effects.

## Quick start
1. Install a simple server (optional) or open `index.html` directly in your browser.
2. Or serve locally from the repo root:
   ```bash
   python3 -m http.server 3000
   ```
3. Visit [http://localhost:3000](http://localhost:3000) to view the page.
